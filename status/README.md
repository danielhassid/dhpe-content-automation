# מערכת הסטטוס של DHPE — למה היא קיימת ואיך היא עובדת

## הבעיה שהיא פותרת

עד היום כל פרסונה (מקיסמה בבוקר, עומרי ברטרו, יאסר...) ייצרה **רשימת משימות משלה מהזיכרון**.
לא היה מקור אמת אחד. התוצאה:

- קיבלת שוב ושוב משימות שכבר עשית — הן אף פעם לא ירדו מהרשימה.
- כשעדכנת בדשבורד — זה לא חלחל לשאר הערוצים.
- "דוחות שבורים" שהומצאו (DHPE-Avi-Bank-Report וכו') חזרו כל יום, למרות שהם לא קיימים.

## הפתרון: מקור אמת יחיד + סוכן סנכרון

```
                 ┌─────────────────────┐
   אתה מעדכן ───▶ │ updates.inbox.md    │  ← המקום היחיד לעדכן
                 └──────────┬──────────┘
                            ▼
                 ┌─────────────────────┐
                 │  סוכן הסנכרון        │  ← קורא, מאמת, מיישם, מנקה
                 └──────────┬──────────┘
                            ▼
                 ┌─────────────────────┐
                 │   ledger.json       │  ← מקור האמת היחיד (SSOT)
                 └──────────┬──────────┘
                            ▼
        ┌───────────────────┼───────────────────┐
        ▼                   ▼                   ▼
    STATUS.md          מקיסמה (בוקר)        עומרי (רטרו)
   (דשבורד קריא)     קוראים מהלידג'ר      קוראים מהלידג'ר
```

## הקבצים

| קובץ | תפקיד | מי עורך |
|---|---|---|
| `ledger.json` | **מקור האמת היחיד**. כל פריט + סטטוס + מקור. | סוכן הסנכרון בלבד |
| `STATUS.md` | דשבורד קריא, נוצר מהלידג'ר. | אוטומטי — אל תערוך ביד |
| `updates.inbox.md` | תיבת עדכונים. אתה כותב, הסוכן מנקה. | **אתה** (וסוכנים) |
| `README.md` | המסמך הזה. | ידני |

## שני חוקי הברזל

1. **שום רשימה לא נבנית מהזיכרון.** כל תדריך/סוכן חייב לקרוא את `ledger.json`
   ולהציג רק פריטים עם סטטוס אקטיבי (`open`, `in_progress`, `broken`).
   `done`/`wontfix`/`phantom` — לעולם לא מוצגים כמשימה.

2. **אין פריט 'שבור' בלי מקור אמיתי.** לכל פריט `broken`/`open` חייב להיות שדה
   `source` שניתן לאמת (קובץ, trigger id, סצנריו). אם אי אפשר לאמת — הוא הופך ל-`phantom`.
   ככה "דוחות רפאים" לא חוזרים.

## איך לחבר את התדריכים הקיימים (מקיסמה / עומרי / יאסר)

בפרומפט של כל תדריך, במקום "רשום מה שבור" — להוסיף:

> קרא את `status/ledger.json` מהריפו. הצג **רק** פריטים שהסטטוס שלהם ב-`_actionable_statuses`.
> אל תמציא פריטים. אם אין פריטים אקטיביים בערוץ — כתוב "אין משימות פתוחות".

זה השינוי היחיד שגורם ל"בוצע" לחלחל לכל הערוצים בבת אחת.
