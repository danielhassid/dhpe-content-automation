# 📥 תיבת עדכונים — כאן מעדכנים סטטוס

זה **המקום היחיד** שבו אתה (או כל סוכן) מעדכן סטטוס משימות.
כתוב שורה אחת לכל עדכון. סוכן הסנכרון יקרא, יעדכן את הלידג'ר, ירנדר מחדש את STATUS.md,
**וימחק את השורות שטיפל בהן** — כך שהתיבה תמיד מתחילה ריקה.

## תחביר (שורה אחת לעדכון)

```
done: <id>                — סמן משימה כבוצעה
open: <id>                — פתח מחדש / הוסף שהיא פתוחה
broken: <id> | <סיבה>     — סמן ריצה כשבורה (עם סיבה אמיתית)
wontfix: <id> | <סיבה>    — הוחלט לא לטפל
note: <id> | <הערה>       — הוסף הערה בלי לשנות סטטוס
new: <id> | <סוג> | <כותרת> | <ערוץ> | <source>   — פריט חדש (source = הוכחה אמיתית!)
phantom: <id> | <סיבה>    — הכרז שפריט הוא רפאים (לא קיים)
```

`<id>` הוא ה-id מהלידג'ר (למשל `sec-rotate-credentials`). אם לא בטוח — כתוב את הכותרת בעברית וסוכן הסנכרון יזהה.

## דוגמאות

```
done: sec-rotate-credentials
note: run-write-sun | הפוסט של השבוע יצא מצוין
```
