# Rotation Logic — איך נקבע התוכן השבועי

## עיקרון מרכזי: נושא שבועי ממוקד

כל שבוע מוקדש ל-**biome/theme אחד**. זה מחזק את האלגוריתם (עקביות נושאית)
וחוסך קרדיטים (אותו עולם ויזואלי).

## הקצב השבועי

| יום | פריט | מקור |
|---|---|---|
| ראשון | **Long-form** של נושא השבוע | content-calendar |
| ראשון | Short #1 (עובדה מהנושא) | נגזר מה-Long |
| שני | Analytics (ב' 08:00) + Coach | weekly |
| שני | Short #2 | נגזר מה-Long |
| שלישי | Short #3 | נגזר מה-Long |
| רביעי | **Long-form** שני (אותו biome או הבא) | content-calendar |
| רביעי | Short #4 | נגזר |
| חמישי | Short #5 | נגזר |
| שישי | Short #6 (הכי "ויראלי" מהשבוע) | נגזר |

→ **2 long-form + ~6 Shorts בשבוע.** כל Short נגזר מנושא long-form (חיה/עובדה בודדת).

## למה Shorts נגזרים מה-Long?

1. חיסכון — אותה דמות, אותו biome, אותם נכסי ויזואל.
2. חיזוק אלגוריתמי — אשכול תוכן סביב נושא אחד.
3. משפך — Short ויראלי → צופה מגלה את ה-Long → שעות צפייה.

## רוטציית biomes (מחזורית)

`Ocean → Forest → Savanna → Garden/Bugs → Arctic → Rainforest → Sky/Weather → Desert → (חזרה)`

## כוונון לפי נתונים (Coach + Analytics)

- אם Shorts מביאים מנויים פי 3 מ-Long → מגדילים יחס Shorts.
- אם biome מסוים זוכה (למשל Ocean) → חוזרים אליו יותר.
- שינוי יחסים מתבצע **רק אחרי הצעת Coach + אישור אנושי**.
