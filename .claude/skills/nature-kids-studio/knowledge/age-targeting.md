# Age Targeting — אנגלית פשוטה לגיל 3-7

## כללי שפה (חוקי ברזל לתסריט)

1. **מקסימום 8 מילים למשפט.** רצוי 5-6.
2. **מילים פשוטות בלבד** — אוצר מילים של גן. אם מילה קשה הכרחית (שם חיה), חוזרים עליה
   ומסבירים: "An octopus — that's a sea animal with eight arms."
3. **זמן הווה.** "The bee flies to the flower" ולא "The bee flew".
4. **פנייה ישירה לילד.** "Can you see the stripes?", "Let's count them!".
5. **חזרה מכוונת** על המילה המרכזית (שם החיה/התופעה).
6. **בלי עגה, בלי דו-משמעות, בלי ציניות.**

## קצב וזמנים

| פרמטר | ערך |
|---|---|
| קצב קריינות | ~120 מילים לדקה (איטי, ברור) |
| Long-form אורך | 3:00-4:30 דקות |
| Long-form מילים | ~400-520 מילים סה"כ |
| Short אורך | 30-50 שניות |
| Short מילים | ~70-110 מילים |
| רגעי [PAUSE 2s] ב-Long | בדיוק 3 (אחרי שאלה, להפסקת מתח לימודי) |
| רגעי [PAUSE] ב-Short | 0-1 |

## מילת מפתח

- מילת המפתח הראשית מופיעה ב-**15 המילים הראשונות** של הקריינות.
- חוזרת לפחות 3 פעמים לאורך הסרטון.

## בטיחות שפה

- בלי הפחדות ("watch out!", "danger!").
- בלי הוראות שילד יחקה בסכנה.
- תמיד מסכמים בנימה חיובית ומרגיעה.
