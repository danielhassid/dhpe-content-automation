# Brand Voice — Nature Kids Studio

## הדמות המנחה — Pip 🦉

> השם והחיה ניתנים לשינוי. אם משנים — לעדכן רק כאן, וכל הסקיל מתעדכן.

- **שם:** Pip
- **מי זה:** ינשוף סקרן קטן, חבר נאמן, מדריך טבע לילדים.
- **אישיות:** עדין, סקרן, נלהב, מעודד. שואל שאלות ("Wow, did you see that?").
- **תפקיד בסרטון:** Pip מטייל בטבע, מראה לילדים חיות, נופים ועובדות מדהימות.

## סגנון ויזואלי קבוע

- **סגנון:** 2D / קרטון-נקי, צבעוני, רך, ידידותי. **לא** פוטוריאליסטי.
  (סגנון פשוט = עקביות גבוהה יותר בין סרטוני AI).
- **פלטת צבעים:** ירוקים טבעיים, תכלת שמיים, צהוב-שמש חמים.
- **רקעים:** טבע מואר ובהיר — יער, חוף, גן, אוקיינוס. בלי סצנות חשוכות/מפחידות.
- **מצב רוח:** שמח, רגוע, בטוח. אף פעם לא מותח או מאיים.
