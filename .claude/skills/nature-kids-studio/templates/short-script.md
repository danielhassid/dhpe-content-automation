# Template — Short Script (30-50 שניות)

> מלא את כל הסוגריים. שמור כ-`videos/[slug]/script-final.md`.

---

**Slug:** `[short-TOPIC-slug]`
**Type:** Short
**Primary keyword:** `[keyword]`
**Date:** `[YYYY-MM-DD]`
**Source long-form:** `[הנושא הארוך שממנו נגזר ה-Short]`

---

## On-screen hook (0-3s)
`[שאלה מסקרנת + טקסט גדול למסך — מקס' 5 מילים]`
דוגמה: "How FAST is a cheetah?"

## Narration (קריינות מלאה)

> חוקים: מקס' 8 מילים למשפט · ~70-110 מילים · מילת מפתח ב-15 המילים הראשונות · הווה.

```
[0-3s]   [Hook — השאלה. מילת המפתח כאן.]
[3-40s]  [התשובה + עובדה אחת מדהימה. ויזואל דינמי. חזרה על המילה.]
[40-50s] [Pip חותם: "Now you know!" + פרידה חמה.]
```

## Visual beats (ל-M&M / Higgsfield)
- Beat 1 (0-3s): `[מה רואים — הדמות/החיה, פעולה]`
- Beat 2 (3-25s): `[...]`
- Beat 3 (25-50s): `[Pip + סצנת סיום]`
- יחס מסך: **אנכי 1080x1920**.

## Loop note
`[איך הסוף מתחבר חזרה להתחלה ללולאה חלקה]`

---

### צ'קליסט לפני אישור התסריט
- [ ] 70-110 מילים
- [ ] מילת מפתח ב-15 מילים ראשונות + חוזרת 3×
- [ ] כל משפט ≤ 8 מילים
- [ ] hook ויזואלי ב-3 שניות
- [ ] בלי תוכן מפחיד/לא הולם (ראה kids-safety-policy.md)
